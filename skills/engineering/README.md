# Engineering

Stable code and AI engineering workflow skills.

- **[eval-planner](./eval-planner/SKILL.md)** - Coordinate a complete eval program and its decision record.
- **[eval-design](./eval-design/SKILL.md)** - Design datasets, metric bundles, slices, and release gates.
- **[eval-build-dataset](./eval-build-dataset/SKILL.md)** - Curate versioned evaluation cases with protected splits.
- **[eval-build-scorer](./eval-build-scorer/SKILL.md)** - Implement auditable deterministic, judge, or human scorers.
- **[eval-validate-scorer](./eval-validate-scorer/SKILL.md)** - Calibrate and stress-test learned evaluators.
- **[eval-run-regressions](./eval-run-regressions/SKILL.md)** - Implement reproducible candidate comparisons and CI gates.
- **[eval-mine-traces](./eval-mine-traces/SKILL.md)** - Find failure clusters and regression cases in traces.
- **[eval-optimize](./eval-optimize/SKILL.md)** - Tune prompts and agent components against protected evals.
