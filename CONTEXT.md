# AI Skillz

A repository of agent skills for AI evaluation, performance tuning, remote compute, problem exploration, and writing.

## Language

**Skill**:
A directory directly under `skills/` containing a `SKILL.md` file, optional `agents/openai.yaml`, and optional bundled resources.

**Evaluation plan**:
A living artifact that turns an AI feature or workflow goal into claims, metrics, datasets, scorers, tasks, risks, and progress tracking.

**Performance contract**:
A project-owned record of useful work, performance goals, preserved behavior, measurement design, experiment bounds, preferences, and a repeatable recipe. The tuning skill reuses the recipe while refreshing measurements and environment evidence.

**Remote compute policy**:
Project-owned provider choices, constraints, budgets, and scoped authorization. Operational observations and ownership/run records are distinct from policy; saved status calculations do not enforce cloud limits or prove live cleanup.

Global skill installation does not make project policy global. Both compute and tuning workflows keep project-specific decisions and evidence with the target project.
