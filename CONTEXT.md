# AI Skillz

A repository of agent skills for planning, evaluating, and operating AI-assisted work.

## Language

**Skill**:
A directory directly under `skills/` containing a `SKILL.md` file, optional `agents/openai.yaml`, and optional bundled resources.

**Evaluation plan**:
A living artifact that turns an AI feature or workflow goal into claims, metrics, datasets, scorers, tasks, risks, and progress tracking.
