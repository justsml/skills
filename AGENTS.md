# Skill development

All changes or additions to skills in this repository must be generalized and broadly applicable within the skill's intended domain. Write reusable guidance that works across projects, users, and supported agent hosts.

Keep project-specific paths, accounts, datasets, budgets, preferences, and one-off task requirements in the consuming project's configuration or artifacts. Use clearly labeled examples and configurable inputs where concrete detail helps. Turn lessons from individual tasks into general decision criteria rather than hardcoded requirements; preserve specialized constraints only when they are intrinsic to the skill's purpose.
